## О проекте

Приложение для пары: вместо разбросанных по переписке ссылок и скриншотов получается один общий список желаний. Каждый добавляет свои хотелки, видит хотелки второго и понимает, что подарить или куда сходить.

Открывается прямо в Телеграме, без установки. Данные лежат в облачной базе, поэтому список одинаковый на всех устройствах.

## Возможности

- **Четыре категории**: подарки, рестораны, места и мелкие радости. Для каждой свои поля, у ресторана ссылка на меню, у места точка на карте
- **Разделение по людям**: переключатель между общим списком, своими желаниями и желаниями второго
- **Уровень желания** от одного огонька до «безумно хочу», чтобы понимать приоритет
- **Фотографии** для каждой позиции, загружаются в хранилище
- **Цена и ссылка** на товар, чтобы не искать заново
- **Карточки в две колонки** с быстрым просмотром и переходом по ссылке
- **Тёмный интерфейс**, подстроенный под оформление Телеграма

## Как устроено

Одностраничное приложение без сборки: чистый Джаваскрипт, оформление на Tailwind, база и хранилище файлов на Supabase. Интеграция с Телеграмом через официальный скрипт мини-приложений, он же отдаёт данные пользователя и подгоняет тему.

```
index.html    разметка, модальные окна, карточки
script.js     логика: фильтры, загрузка, сохранение, работа с базой
style.css     цвета, карточки, эффект стекла
```

## Запуск

1. Создайте проект в Supabase и таблицу для желаний с полями: название, категория, автор, цена, ссылка, точка на карте, уровень желания, фото
2. Подставьте адрес проекта и публичный ключ в `script.js`
3. Положите файлы на любой статичный хостинг, например GitHub Pages
4. В BotFather укажите этот адрес как мини-приложение для своего бота

Для проверки в браузере приложение работает и без Телеграма, часть возможностей с пользователями при этом отключается.

## Что можно доделать

- Напоминания о днях рождения и годовщинах
- Общий бюджет и подсчёт стоимости списка
